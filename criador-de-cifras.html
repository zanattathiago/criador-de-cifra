Importar músicas

Salvar as cifras no GitHub

As cifras ficam no arquivo cifras.json do repositório criador-de-cifra. Qualquer computador ou celular que abrir o site carrega as músicas de lá. Para salvar, este navegador precisa de uma chave do GitHub, que fica guardada só aqui.

Crie em github.com/settings/personal-access-tokens/new: em Repository access escolha só criador-de-cifra, e em Permissions dê Contents: Read and write.
